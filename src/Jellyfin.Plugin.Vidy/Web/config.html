Vidy

Search TMDB from Jellyfin and play titles through the Vidy embed player. TMDB data is provided by The Movie Database; this product uses the TMDB API but is not endorsed or certified by TMDB.

TMDB API
Create a free key at themoviedb.org → Settings → API. Either the v3 API key or the v4 "API Read Access Token" works. The key stays on the server and is never sent to browsers.
